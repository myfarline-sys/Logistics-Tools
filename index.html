⚙ Auto-Sync & Hantar Data ke Google Sheets

Sambungkan aplikasi ini terus ke fail Loading Capacity V3.0 (termasuk tab Log Kombinasi) di Google Sheets supaya anda boleh Sync automatik daripada telefon atau PC!

📋 Cara Pasang Apps Script (Sekali Sahaja - 2 Minit)
  1. Buka fail Loading Capacity V3.0 di Google Sheets.
  2. Tekan menu Extensions → Apps Script.
  3. Pastikan kod Web App memulangkan semua helaian (termasuk Log Kombinasi).
  4. Tekan Deploy → Manage deployments → Edit → New version → Deploy.
  5. Salin Web app URL (.../exec) & tampal dalam kotak di atas!

🔑 Panduan API Key & Privasi Telefon Rakan Sekerja
1. Simpanan di Telefon Sendiri Sahaja: API Key dan tetapan AI yang anda masukkan di sini hanya disimpan dalam penyimpanan pelayar telefon anda sendiri (localStorage)—tidak dihantar ke pelayan luar atau dikongsi bersama fail apabila pautan/fail dihantar kepada rakan sekerja.

Cara Meletakkan API Key pada Telefon Rakan Sekerja: Buka pautan/fail aplikasi di telefon rakan sekerja → buka AI Quick Ask → buka bahagian Tetapan Gemini API Key di bawah → tampal API Key mereka sendiri → tekan Simpan Key. (Tanpa API Key, semakan Log Kombinasi, kiraan PVD pallet & draf WA tetap berfungsi secara lokal).
