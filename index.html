⚙ Auto-Sync & Hantar Data ke Google Sheets

Sambungkan aplikasi ini terus ke fail Loading Capacity V3.0 di Google Sheets supaya anda boleh Sync automatik dan simpan rekod baharu terus ke Google Sheets daripada telefon!

📋 Cara Pasang Apps Script (Sekali Sahaja - 2 Minit)
  1. Buka fail Loading Capacity V3.0 di Google Sheets.
  2. Tekan menu Extensions → Apps Script.
  3. Padam kod asal & tampal kod V6.7 di bawah, kemudian tekan ikon Save.
  4. Tekan Deploy → New deployment → pilih jenis Web app (atau Manage deployments → Edit → New version jika sudah ada).
  5. Set Execute as: Me & Who has access: Anyone → tekan Deploy.
  6. Salin Web app URL (.../exec) & tampal dalam kotak di atas!
